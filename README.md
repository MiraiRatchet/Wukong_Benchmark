# Wukong Benchmark Automator

C#-инструмент для автоматизированного запуска **Black Myth: Wukong Benchmark Tool** из Steam. Прогоняет два теста (CPU и GPU) с разными настройками графики, парсит результаты и выводит отчёт.

## Что делает

1. **Находит путь к бенчмарку через Steam** — учитывает все библиотеки (`libraryfolders.vdf`), а не только папку по умолчанию. Работает с игрой, установленной на любом диске.
2. **Делает бэкап текущих настроек графики**
3. **Прогоняет два теста последовательно:**
   - **CPU-тест** — минимальная нагрузка на GPU (низкое разрешение, low-качество, RTX и DLSS выключены), чтобы изолировать производительность процессора.
   - **GPU-тест** — максимальная нагрузка на видеокарту (4K, epic-качество, RTX включён).
4. **Парсит результаты** из JSON-файла, который бенчмарк создаёт после каждого прогона.
5. **Восстанавливает оригинальные настройки** — файл конфига вернётся к исходному состоянию.

## Требования

- **Windows 10+**
- **.NET 8**
- **Steam** с установленным **Black Myth: Wukong Benchmark Tool**, который прогнали 1 раз (чтобы появились настройки пользователя).

## Сборка и запуск

```bash
git clone https://github.com/MiraiRatchet/Wukong_Benchmark.git
cd Wukong_Benchmark
dotnet build -c Release
```

Билд лежит в `\WukongBenchmarkAutomator\WukongBenchmarkAutomator\bin\Release\`## Обоснование настроек

### CPU-тест

Цель — **минимизировать нагрузку на GPU**, чтобы итоговый FPS определялся процессором.

| Параметр | Значение | Зачем |
|---|---|---|
| `ResolutionSizeX` | `1280` | Малое разрешение — GPU не успевает стать узким местом |
| `ResolutionSizeY` | `720` | То же самое |
| `sg.ResolutionQuality` | `30` | Внутренний рендер идёт в 30% от разрешения — ещё сильнее снижает нагрузку на GPU |
| `ViewDistance` | `0` | Отключены дальние объекты — нагрузка на CPU и GPU |
| `sg.ShadowQuality` | `0` | Тени — самая дорогая для CPU опция рендера |
| `sg.TextureQuality` | `0` | Минимальный размер текстур |
| `sg.EffectsQuality` | `0` | Отключены эффекты частиц и постобработка |
| `sg.FoliageQuality` | `0` | Минимум растительности |
| `sg.GlobalIlluminationQuality` | `0` | Отключено глобальное освещение (GI) |
| `sg.ReflectionQuality` | `0` | Отключены отражения |
| `sg.AntiAliasingQuality` | `0` | AA — дорогая операция, отключаем |
| `sg.PostProcessQuality` | `0` | Постобработка отключена |
| `sg.ShadingQuality` | `0` | Шейдинг минимального качества |
| `sg.RayTracingQuality` | `0` | RTX — самая дорогая для GPU опция, выключена |
| `("Rtx", "0")` | `0` | RTX выключен на уровне UI |
| `("RtxLevel", "0")` | `0` | Уровень RTX минимальный |
| `("Dlss", "0")` | `0` | DLSS не искажает результат |

При таких настройках GPU загружен слабо, а процессор выполняет всю игровую логику — его производительность и определяет FPS.

### GPU-тест

Цель — **максимально нагрузить видеокарту**.

| Параметр | Значение | Зачем |
|---|---|---|
| `ResolutionSizeX` | `3840` | 4K — большая нагрузка на видеопамять и блоки растеризации |
| `ResolutionSizeY` | `2160` | То же самое |
| `sg.ResolutionQuality` | `100` | Полное разрешение, без апскейла |
| `sg.ViewDistanceQuality` | `4` | Максимальная дальность прорисовки |
| `sg.ShadowQuality` | `4` | Epic-тени со всеми деталями |
| `sg.TextureQuality` | `4` | Текстуры максимального разрешения |
| `sg.EffectsQuality` | `4` | Все эффекты и постобработка на максимуме |
| `sg.FoliageQuality` | `4` | Плотная растительность на максимуме |
| `sg.GlobalIlluminationQuality` | `4` | Полноценное GI (Lumen или аналог) |
| `sg.ReflectionQuality` | `4` | Детальные отражения |
| `sg.AntiAliasingQuality` | `4` | Максимальное сглаживание |
| `sg.PostProcessQuality` | `4` | Все постэффекты включены |
| `sg.ShadingQuality` | `4` | Шейдинг максимального качества |
| `sg.RayTracingQuality` | `1` | RTX включён — нагрузка на RT-ядра |
| `("Rtx", "1")` | `1` | RTX включён на уровне UI |
| `("RtxLevel", "2")` | `2` | Максимальный уровень RTX |
| `("Dlss", "1")` | `1` | DLSS Quality — характерный игровой сценарий |

При таких настройках CPU практически не участвует в рендере, а GPU работает на пределе.
